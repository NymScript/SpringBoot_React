## Aprendiendo POO

Dedicado a la práctica y aprendizaje de los conceptos fundamentales de la Programación Orientada a Objetos (POO)

Clases y Objetos: Entender cómo se crean y utilizan objetos a partir de clases.
Encapsulamiento: Proteger los datos dentro de una clase y exponer solo lo necesario.
Herencia: Reutilizar código a través de la creación de clases derivadas.
Polimorfismo: Implementar múltiples formas de un método o función.
Abstracción: Simplificar la complejidad mostrando solo lo esencial.
